# Schedule 1 Helper

GitHub-only static web app for Schedule I / Hyland Point.

## Current build

- large real Hyland Point 2D map reference with the original map-icon layer
- mouse/touch-friendly zoom and pan
- factual map legend based on published Schedule I map-guide labels
- 66-customer database
- customer search
- district and tier filters
- customer detail panel
- orders/week and budget fields
- Recipe Finder
- recipe search by name, ingredient and effect
- drug filter: Meth, Weed, Shrooms, Cocaine
- ingredient order shown explicitly
- cost, sell price and profit
- recipe records from published community data plus the user-supplied 8-ingredient recipe
- separate JSON data for customers, recipes, buildings, roads and props
- 3D mode intentionally marked Coming Soon
- no invented customer coordinates

## Map legend

The legend uses local SVG assets visually reproduced from the user-provided real Hyland Point map screenshot. Public map sources are used to cross-check the category names; these SVGs are not claimed to be extracted internal game files.

Currently included local assets:
- ATM
- Recycler
- Telephone Booth
- Post Office
- Area / Location
- Main Mission
- Shop / Business
- Hardware

The public interactive map also documents these layers:

- Customers
- Dealers
- Properties
- Businesses
- Customer groups
- Districts

## Accuracy

The public interactive map is still being surveyed and explicitly notes that some customer locations are not yet confirmed. This project therefore does not invent coordinates or present reconstructed geometry as 1:1.
